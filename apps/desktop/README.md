# harpyhare

Push-to-talk приложение для macOS и Windows: зажми хоткей записи → захват системного звука → распознавание речи через Whisper (Groq) → редактирование текста → отправка в Claude со скриншотами. Ответ приходит стримом прямо в плавающем HUD-окне. В системе процесс представляется нейтрально как «Audio System»; бренд harpyhare — только внутри интерфейса.

## Требования

- macOS 14.2+ (захват системного звука через Core Audio process tap) **или** Windows 10 версии 2004+ / Windows 11, x64 (захват через WASAPI loopback; версия 2004 нужна для скрытия окна при демонстрации экрана)
- Ключ API [Anthropic](https://console.anthropic.com/) (Claude)
- Ключ API [Groq](https://console.groq.com/) (Whisper STT)
- VPN для обоих сервисов при работе из РФ

## Запуск и сборка

```bash
npm install
cp .env.example .env   # и впиши ключи API (см. ниже)
npm run tauri dev      # dev-режим с hot-reload
npm run tauri build    # production-сборка (.app + .dmg на macOS, установщик NSIS на Windows)
```

## Ключи API

Два способа задать ключи (можно совмещать):

1. **`.env` в корне проекта** — `ANTHROPIC_API_KEY` и `GROQ_API_KEY`. Файл в `.gitignore` и подхватывается при старте приложения.
2. **Настройки в приложении** (⚙) — сохраняются в settings.json и **имеют приоритет** над `.env`: значение из `.env` используется, только пока соответствующее поле в настройках пустое.

## Первый запуск

На macOS при первом старте система спросит «Разрешить Audio System записывать системный звук?» — нажми **Разрешить**. Если диалог не появился или было отказано, выдать доступ можно на экране «Доступы» в лаунчере.

На Windows отдельных разрешений не требуется: WASAPI отдаёт loopback устройства вывода без запроса, снимок экрана — тоже. Экраны «Доступы» и «Маскировка» там не показываются (маскировка облика — механика macOS-бандла).

## Горячие клавиши

Основной модификатор платформенный: на macOS — ⌘, на Windows — Ctrl (клавиша Win под модификатор не отдаётся — она занята системным снапом окон).

| Клавиша | Действие |
|---------|----------|
| F9 (зажать) | Начать запись системного звука |
| Esc | Отменить запись |
| ⌘/Ctrl+Enter | Отправить текст в Claude |
| ⌘/Ctrl+Shift+S | Снимок области экрана |
| ⌘/Ctrl+Shift+H | Скрыть или показать окно |
| ⌘/Ctrl+←/→/↑/↓ | Двигать окно по экрану |

> **ВАЖНО:** хоткей записи перехватывает нажатие во **всех** приложениях, пока приложение запущено. В полях самого приложения печать работает нормально — PTT снимается при получении фокуса. Все сочетания настраиваются в лаунчере.

## Настройки

Открываются кнопкой ⚙ в правом верхнем углу. Хранятся в:

```
macOS:   ~/Library/Application Support/com.audioservice.helper/settings.json
Windows: %APPDATA%\com.audioservice.helper\settings.json
```

На macOS файл создаётся с правами 600 (читает только текущий пользователь); на Windows приватность даёт сама папка профиля — POSIX-режимов там нет.

## Обновления

Приложение само проверяет новые версии (на старте и раз в 6 часов) по `latest.json` из публичного репозитория [harpyhare-releases](https://github.com/screenfriskofficial/harpyhare-releases). При находке в шапке появляется бейдж с номером версии: клик → заметки релиза → «Обновить и перезапустить» (артефакт проверяется minisign-подписью). Ручная проверка — в настройках.

## Релиз

Одноразовая настройка: пара ключей подписи updater-артефактов уже сгенерирована в `~/.tauri/itech.key` (+ `.pub`). **Приватный ключ обязательно забэкапить**: без него существующие установки перестанут принимать обновления. Публичный ключ зашит в `tauri.conf.json` (`plugins.updater.pubkey`).

```bash
npm run release -- 0.2.0 --notes "Что нового"
```

Скрипт бампит версию в трёх файлах, собирает подписанный бандл **той платформы, на которой запущен**, публикует артефакты и `latest.json` в harpyhare-releases и делает локальный коммит с тегом `vX.Y.Z` (пуш — вручную). Ключ ищется в `~/.tauri/itech.key` (переопределить: `ITECH_SIGNING_KEY`).

Релиз двухплатформенный, и собрать Windows-бандл на macOS нельзя. Порядок такой:

1. на macOS — `npm run release -- X.Y.Z --notes "…"`: создаёт релиз с `AudioSystem_X.Y.Z_aarch64.app.tar.gz`, `.dmg` и `latest.json` с платформой `darwin-aarch64`;
2. вторую платформу **доливают** на том же теге: версия не бампается, тег не ставится, в релиз добавляется `AudioSystem_X.Y.Z_x86_64-setup.exe`, а платформа `windows-x86_64` вливается в существующий `latest.json`. Способа два:
   - на Windows (машина или CI-раннер) — `npm run release -- X.Y.Z`;
   - с macOS — `npm run release -- X.Y.Z --windows-setup путь/к/AudioSystem_X.Y.Z_x64-setup.exe`: берёт установщик из артефакта `windows-installer` CI-джобы (`.github/workflows/ci.yml`), подписывает его локальным `~/.tauri/itech.key` и доливает. Ничего не собирает; имя файла обязано содержать `_X.Y.Z_`. **Артефакт есть не у каждого прогона:** джоба собирает установщик только на пуше тега `v*` — то есть после `git push --tags` из шага 1 — либо по ручному `workflow_dispatch`; на обычных пушах в main и на PR его нет.

   На Windows установщик служит и ссылкой для человека, и артефактом апдейтера (в Tauri 2 апдейтер переиспользует сам `-setup.exe`). Windows-машина для релиза не обязательна: updater-подпись — minisign по байтам файла, и машина сборки для неё безразлична.

**Оставлять релиз без второй платформы нельзя.** Апдейтер на ней не «молча не находит обновление», а падает с ошибкой при каждой проверке: в плагине `get_urls` зовётся до сравнения версий и без ключа платформы отдаёт `TargetsNotFound`. Установленные версии другой платформы это не ломает. Код под Windows без Windows-машины проверяет GitHub Actions — но на каждом пуше только компиляцией (clippy), а бандл собирает лишь на теге; подпись там включается, только если в секретах есть `TAURI_SIGNING_PRIVATE_KEY`.

## Стек

- **Frontend:** React 19 + Vite + TypeScript + Tailwind v4 + shadcn/ui + react-markdown. Слои: `src/ipc` (типизированная граница над Tauri — единственное место, знающее про invoke/listen), `src/lib` (чистая логика), `src/hooks` (по хуку на слайс контракта), `src/components` (на shadcn-примитивах).
- **Backend:** Rust (Tauri 2) — захват системного звука (Core Audio process tap на macOS, WASAPI loopback на Windows), Groq STT, стрим Anthropic. Платформенный код изолирован в `<модуль>/macos.rs` и `<модуль>/windows.rs` за общим фасадом `<модуль>.rs`.
